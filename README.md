Pony Roulette!

A web app by Sound Byte!

I decided to make a simple web app thing using html and js
that selects a random pony from a pre-determined list to help with art block



"How does it work?"

It selects a random pony from a list of derpibooru thumbnails determined by me, there are no weights
and is completely random



"How do i use it?"

Just install PonyRoullete.html and run it in your browser, to reroll either refresh the page or press the "reroll" button
